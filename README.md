# ChainSkin

ChainSkin enables real-time, distributed data aggregation and event-driven processing via a high-performance, multi-node architecture.

The key benefits of using ChainSkin include:

- ChainSkin enables real-time, distributed data
- aggregation and event-driven processing via
- a high-performance, multi-node architecture

- rust
- rust framework (Flask/Django/FastAPI or equivalent)
- Pytest for testing

## Installation

1. Clone the repository: `git clone https://github.com/Anabelengil/ChainSkin.git`
2. `cd ChainSkin`
3. Install in editable mode: `pip install -e .`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
